# advantage-automacao

# Preparação do ambiente

Instalar Node.JS;

Verificar a instalação: node --version;

Criar o projeto node (package.json): npm init –y;

Instalar o Cypress (na pasta do projeto): npm install cypress;

Após a instalação execute: npx cypress open;

Suporte em: https://docs.cypress.io/app/get-started/install-cypress
